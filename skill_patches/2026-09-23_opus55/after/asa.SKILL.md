# 朝の整理スキル（asa）

朝の総合ハブ。サイボウズ Office を読み取り、(1) スケジュールをGoogleカレンダーへ同期、(2) ワークフロー未処理を一覧化、(3) Myフォルダ新着を分類して返信案を作り、(4) 会社メール（理想メーラー）・案件発注情報を確認し、(5) 今日のやることリストを出力する。（2026-07-05 会社メールの窓口をGmailへ依存しない運用へ移行し、2026-08時点の正本は理想メーラー）
さらに既存ルーティン（メール取込・週次インプット・金曜夜間一括）を**曜日対応モジュール**として集約実行する（後述）。
**運用は「平日3時の自動実行（STEP A）＋朝の手動実行」の二段構え**（2026-09-02 grillingで決定）。3時にアプリ内の定期タスク `asa-daily` が下ごしらえを済ませ、朝「/asa」と叩いたときは**その結果を読み込んで差分だけ**取り直す。ゼロから全部やり直さない。

> 2026-06-13に停止した「無人 claude -p」の禁止は**解除した**。禁止の理由だった課金分離は、Telegram窓口（tg_bridge.py）が既に `claude -p` を日常的に回している時点で実態と合わなくなっていた。ただし**CLI版の claude は mytasks と risou-mailer しかMCPを持たず、launchd経由ではGoogle Driveの既存ファイルも読めない**（TCC・2026-09-02実測）。だから自動実行はCLIでなく**このClaudeアプリの定期タスク**に置く。ここを取り違えると、サイボウズもカレンダーもDriveも触れないまま「正常終了」する。

## 大前提（厳守）

- **返信は絶対に自動送信しない。** 返信案はチャットに表示するだけ。サイボウズへの入力・送信は米谷さんの承認後のみ。
- ワークフローの承認/差戻しも勝手に押さない。内容点検→チャットで提案まで。
- 文中に「！」を使わない。サイボウズ文面は段落間の空行なし。

## STEP A：自動モード（平日3時・無人実行）

> アプリ内の定期タスク `asa-daily`（cron `0 3 * * 1-5`）から起動される工程。**この節は無人実行時だけ読む**。手動の /asa は STEP 0 から始める。

### A-0 絶対条件（無人だから守る）
- **送信・申込・支払い・削除はしない。** メールは `save_draft` の下書きまで。マイタスクは登録・更新まで（完了・削除はしない）。
- **ブラウザは読み取りのみ**（navigate・get_page_text・read_page・find・browser_batch）。クリック・入力・JavaScriptは使わない。
- **止まらない。** サイボウズがログイン切れ・拡張未接続なら「サイボウズ：未取得（理由）」と記録して次へ進む。1か所の失敗で全部を落とさない。
- 開いたタブは終了前に必ず閉じる。
- 所要は60分を上限の目安にする。超えそうなら残りを「未着手」と明記して打ち切る。

### A-1 やること
1. STEP 0（マイタスク先読み）→ STEP 1〜4C を通常どおり実行する。STEP 0D（受信箱の件数）と STEP 4D（大容量転送の取込）は**手動側の担当**なので飛ばす。
2. 順位づけは STEP B のルールで行う。
3. **上位5件まで先回りする**：調べもの・資料の下読み・要点抽出・返信下書き（`save_draft`）・社内ファイルの下ごしらえまで。判断が要るものは承認カードの形に整えるだけにする。
4. **マイタスクの並び順そのものを優先順に書き換える**（STEP C）。米谷さんはPWA・ウィジェットで上から順に見るので、順位はチャットの中だけでなく現物へ反映する。
5. 成果を `01_業務ナレッジ/業務ナレッジ/Inbox/YYYY-MM-DD_asa.md` へ STEP 6 の構成で書き出す。先回りの結果と承認カードもこのファイルに含める。
6. 最後に Telegram へ要約を送る（1200字以内）。⚠️**`tg_notify.py` は使わない**。内部が urllib のため python.org 版 python3 では `CERTIFICATE_VERIFY_FAILED` で必ず落ちる（2026-09-02・09-03に連続で踏んだ）。**curl で直接叩く**：

```bash
TOKEN=$(python3 -c "import json;print(json.load(open('$HOME/.claude/telegram-bridge/config.json'))['bot_token'])")
CHAT=$(python3 -c "import json;print(json.load(open('$HOME/.claude/telegram-bridge/config.json'))['chat_id'])")
cat > /tmp/asa_msg.txt <<'MSG'
朝の下ごしらえが終わりました（M月D日）
■今日の順番
①…
■承認待ち（返信してください）
・…
■要注意
・…
MSG
curl -s -X POST "https://api.telegram.org/bot${TOKEN}/sendMessage" \
  --data-urlencode "chat_id=${CHAT}" --data-urlencode "text@/tmp/asa_msg.txt"
```

本文はヒアドキュメントでファイルへ書いてから `text@ファイル` で渡す（引数へ直に長文を入れると引用符で壊れる）。

失敗・中断したときも、理由を同じ経路で必ず送る（黙って終わらない）。

### A-2 朝の手動実行との接続
朝「/asa」と叩かれたら、まず当日の `Inbox/YYYY-MM-DD_asa.md` を読む。存在すれば**3時以降の差分だけ**取り直す（新着メール・サイボウズの更新・カレンダーの変更）。存在しなければ通常どおり STEP 0 から回す。

## STEP C：マイタスクの並び順を書き換える（自動モードで毎朝／手動でも依頼時）

順位を決めたら、**マイタスクの現物の並びも上から優先順にする**（2026-09-02 米谷さん指示）。ウィジェットとPWAは上から順に見るものなので、順位が頭の中とチャットにしか無いと意味がない。

**MCP の `update_task` では並び順を変えられない**（title/note/due/repeat/list_id/status しか受け付けない）。並べ替えは Worker の API を直接叩く。

```bash
TOKEN="$(head -n1 "$HOME/Library/Application Support/RisouMailer/.mytasks-api-token")"
# 1. 現物を取る（並べ替えは list ごと・未完了の全件を渡す必要がある）
curl -s -H "Authorization: Bearer $TOKEN" \
  "https://mytasks.yonetani32ai.workers.dev/api/tasks?status=open" -o /tmp/mytasks_now.json
# 2. ordered_ids に「そのリストの未完了タスク全件」を優先順に並べて PATCH する
curl -s -X PATCH "https://mytasks.yonetani32ai.workers.dev/api/tasks/reorder" \
  -H "Authorization: Bearer $TOKEN" -H "content-type: application/json" \
  --data-binary @/tmp/reorder_work.json
# body = {"list_id":"work","ordered_ids":[<id>,…全件…],"moved_id":<先頭id>,"learning_actor":"ai"}
```

手順の要点：
- **`ordered_ids` はそのリストの未完了全件**。1件でも欠けると `409` で弾かれ、何も書き換わらない（安全側の設計）。**409 は失敗ではなく「その間にタスクが増減した」の合図**なので、取り直して並べ直す。
- 渡すのは `task_number`（MYT-0444）ではなく**内部の `id`**（8桁）。取り違えると 409 になる。
- `python3` の urllib は python.org 版の証明書が入っておらず `CERTIFICATE_VERIFY_FAILED` で落ちる。**curl を使う**（[[feedback_mac_runtime_precheck]]）。
- 書き換える前に取得した JSON を控えておく（`~/Library/Application Support/Claude/mytasks-backup/`）。並び順しか変わらないが、戻せるようにしておく。
- 並べ替えは `work` と `private` を別々に流す。
- 完了・削除はしない。並び順だけを触る。

## STEP 1B：サイボウズ3点の一括取得（推奨・1往復）

   ```bash
   python3 -c 'import zipfile,os,sys
zp,dest=sys.argv[1],sys.argv[2]
with zipfile.ZipFile(zp) as z:
    for i in z.infolist():
        n=i.filename if i.flag_bits & 0x800 else i.filename.encode("cp437").decode("cp932")
        t=os.path.join(dest,n); os.makedirs(os.path.dirname(t),exist_ok=True)
        if not i.is_dir(): open(t,"wb").write(z.read(i))' "$zip" "$dest"
   ```
